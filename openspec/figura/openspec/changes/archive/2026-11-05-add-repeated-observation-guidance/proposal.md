## Why

当前 Agent 只有通用的避免重复调用提示，模型重复 OCR 或测量且得到相同观察时，缺少与已提交事实关联的具体反馈。需要让模型看见重复观察，帮助其调整方法或带限制交付，同时保留合理补测与自主决策空间。

## What Changes

- 从当前 Run 已提交的成功 `extract_text`、`measure_chart` 调用计算相同动作与相同结构化观察，第二次出现后产生具体提醒，允许中间穿插其他动作。
- 在下一普通模型请求的动态运行状态层加入合并后的重复次数、最近两次来源引用与收敛建议；不修改工具结果，不追加用户消息。
- 保留所有调用权限，不新增缓存复用、自动拦截、无进展评分、Run 总预算或测量决策状态。
- 从持久事实重建提醒，保持压缩、重启和冻结 Provider 请求重试的一致性。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `agent-react-execution`: 增加当前 Run 内重复成功视觉观察的事实判定、动态提醒及恢复边界。

## Impact

- 影响 `src/figura/agent/` 的调用期事实投影、普通请求构建和 Prompt 资产，以及对应 Agent/请求/恢复测试与实现文档。
- 复用 Runtime 工具事实和既有来源引用；无数据库迁移、公共 API/SSE、前端或工具输入输出合同变化，无新增依赖。
- 不修改旧 `chartagent`；不改变已有 Provider 重试、工具恢复、执行所有权与无累计 Run 配额的合同。
