## 1. 建立统一的测量证据模型

- [x] 1.1 定义统一的测量质量信封，覆盖生命周期状态、质量摘要、结构化问题、来源、作用域、尝试信息和可引用的视觉证据，同时保留柱状图、折线图、饼图、散点图各自的数据字段
- [x] 1.2 实现 `MeasurementSession` 与 `MeasurementAttempt` 的运行级模型，记录 `attachment_id`、`panel_id`、`attempt_id`、父尝试、工具、作用域、质量结果和证据引用，并限制历史长度与字段大小
- [x] 1.3 为测量会话和尝试增加序列化、反序列化、状态转换与来源一致性校验，确保不同面板、不同附件、不同运行之间不能复用错误证据
- [x] 1.4 为统一模型补充单元测试，覆盖初始临时状态、接受、需重新测量、部分可用、不支持、失败、重复事件、超限字段和跨面板引用

## 2. 统一四类测量工具的输出与质量审计

- [x] 2.1 适配柱状图、折线图、饼图、散点图测量工具，使其输出统一质量信封，同时不破坏现有图表专属结果字段
- [x] 2.2 实现代码负责的确定性质量审计，至少检查作用域、几何关系、坐标校准、数据覆盖、系列或扇区关联、视觉证据引用和明显冲突，并将问题转换为有严重级别、位置和下一动作的结构化 issue
- [x] 2.3 明确质量状态判定规则：存在阻断性问题时不得标记为 `accepted`；没有阻断性问题但覆盖不完整时标记为 `partial`；无法可靠判断时保留 `provisional` 或 `unsupported`，不得用单一 confidence 绕过审计
- [x] 2.4 为没有统一信封的旧测量结果提供兼容解析，但统一降级为 `provisional`，并保留原始结果供诊断；不在本 change 中实现任意区域重测、SAM 或 OCR 算法
- [x] 2.5 为四类测量工具分别补充正常、部分覆盖、几何错位、坐标校准异常、来源缺失和审计失败测试，验证图表专属数据与统一质量信息同时存在

## 3. 接入 Agent 会话、产物索引与检查点

- [x] 3.1 将测量会话注册到当前 run 的 memory/artifact 管理链路，使每次测量都能关联到准确的附件、面板和来源产物
- [x] 3.2 将测量尝试、质量状态、issue、父子关系和证据引用写入 artifact index 与 checkpoint，并保持可恢复、可审计且不写入原始图片字节、绝对路径或 provider 原始 payload
- [x] 3.3 增加恢复时的幂等与一致性处理：重复回放不得重复创建有效尝试，过期或来源不匹配的尝试不能恢复为当前面板的可接受证据
- [x] 3.4 补充中断、重连、检查点恢复、重复事件、旧格式检查点和损坏引用的测试，确认恢复后状态仍能被后续组装链路识别

## 4. 在 `assemble_spec` 前建立质量门禁

- [x] 4.1 设计由服务端生成的测量引用和来源元数据，使组装请求能够绑定到精确的附件、面板、会话和尝试，而不是只携带模型自由填写的 confidence
- [x] 4.2 在 `assemble_spec` 内实现测量来源校验：来源存在、附件和面板匹配、尝试属于当前 run/session、状态为 `accepted`、没有未处理阻断 issue，任一条件不满足都拒绝直接采用测量数据
- [x] 4.3 为门禁失败返回稳定、可序列化的结构化结果，包含失败原因、受影响字段或区域、当前质量状态、允许的下一动作和可追踪的尝试引用；不得静默猜值或直接结束整个 run
- [x] 4.4 让接受的测量证据以 provenance 写入 ChartSpec，至少保留附件、面板、会话和尝试标识；直接视觉组装且没有测量证据的单 ChartSpec 继续兼容现有路径
- [x] 4.5 补充组装层测试，覆盖接受证据、临时证据、部分证据、阻断 issue、来源错配、跨面板引用、重复组装、旧测量结果和无测量直接组装

## 5. 更新主流程提示词与可观测性

- [x] 5.1 更新静态主流程提示词，明确测量结果先经过质量门禁，模型不得把 `provisional`、`partial` 或带阻断 issue 的结果当作最终事实，也不得自行伪造 accepted 标记
- [x] 5.2 更新动态上下文与工具结果注入格式，区分原始观测、质量审计结果、接受证据和门禁失败动作，并将面板作用域与尝试 lineage 一并呈现给模型
- [x] 5.3 为测量质量状态、门禁判定、拒绝原因和恢复动作增加结构化日志或 trace 字段，确保不记录图片内容、密钥、绝对本地路径和完整 provider payload
- [x] 5.4 增加提示词、工具结果 schema 和 trace 字段的回归测试，验证中英文用户输入下技术标识保持稳定，且模型可获得下一动作而不是只看到一个失败字符串
