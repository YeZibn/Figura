## 面板 1：Quarterly Sales

| 项目 | 内容 |
|---|---|
| 标题 | Quarterly Sales |
| 图表类型 | 分组柱状图（垂直；两系列并排） |
| 横轴 | Quarter（季度）：Q1 → Q2 → Q3 → Q4 |
| 纵轴 | Revenue (million USD)，刻度 0–70，步长 10；单位为百万美元 |
| 系列 | Target（蓝色）、Actual（橙色）；图例顺序：Target 在左、Actual 在右 |

| 类别 | Target | Actual |
|---|---|---|
| Q1 | 40 | 36 |
| Q2 | 55 | 51 |
| Q3 | 48 | 45 |
| Q4 | 62 | 59 |

说明：这 8 个数值在图中都带有数据标签（40、36、55、51、48、45、62、59）；我另外按柱顶像素与纵轴刻度校准做了独立核算，结果与标签一致（偏差 < 0.1）。因此本面板数值属于图上标注值，不是估值。

## 面板 2：Monthly Orders

| 项目 | 内容 |
|---|---|
| 标题 | Monthly Orders |
| 图表类型 | 折线图（单系列，带圆点标记） |
| 横轴 | Month（月份）：Jan → Feb → Mar → Apr → May → Jun → Jul |
| 纵轴 | Number of Orders，刻度 0–60，步长 10；图中未标注单位（计数） |
| 系列 | Orders（绿色） |

| 类别 | Orders（估算） |
|---|---|
| Jan | ≈ 22.1 |
| Feb | ≈ 28.0 |
| Mar | ≈ 25.0 |
| Apr | ≈ 36.0 |
| May | ≈ 44.1 |
| Jun | ≈ 41.1 |
| Jul | ≈ 53.1 |

说明：该面板没有数据标签，上表数值全部为**点位估算**（依据纵轴 10 个单位 ≈ 81 像素的刻度校准，单点误差约 ±0.25）。按图形精度看，原始值很可能是 22、28、25、36、44、41、53 这样的整数值，但图上未标注，不能作为精确值引用。

## 读图时的两点提示

- 柱状图测量把标题文字误判成一个“系列”（报了 15 根柱、3 个系列），并误判为堆叠模式；实际的 8 根柱因为并排显示，应作为**分组**模式读取，第三“系列”不是真实数据。
- 折线图在 Jan 处多报了一个 y≈62.6 的点，那是图例中的样例线段；Jan 的真实点位是 y≈22.1，图中只有一条连续的 Orders 折线。
