## 当前有效的图表合同

**整体结构**
| 项 | 约定 |
|---|---|
| 布局 | 一行两列（1 行 × 2 列），左=季度销售，右=月度订单 |
| 总标题 | 未指定具体文字；不使用原数据中不存在的标题 |
| 面板独立性 | 两个面板各自保留标题、横轴、纵轴、单位；数值不合并、不共用坐标、不做跨面板换算 |

**左侧面板：季度销售**
| 项 | 约定 |
|---|---|
| 标题 | Quarterly Sales |
| 图表类型 | 分组柱状图（grouped bar，垂直方向，类别在 x 轴） |
| 横轴 | 名称 “Quarter”；类别顺序固定为 Q1、Q2、Q3、Q4（4 个） |
| 纵轴 | 名称 “Revenue (million USD)”；单位：百万美元；合同范围 0–70，刻度间隔 10 |
| 系列与图例 | Target = 40、55、48、62；Actual = 36、51、45、59（均按 Q1→Q4）；图例必须显示 Target 与 Actual 两项 |
| 数据形状 | 4 类别 × 2 系列 = 8 个数值 |

**右侧面板：月度订单**
| 项 | 约定 |
|---|---|
| 标题 | Monthly Orders |
| 图表类型 | 折线图（line；x 为类别型时间标签） |
| 横轴 | 名称 “Month”；类别顺序固定为 Jan、Feb、Mar、Apr、May、Jun、Jul（7 个） |
| 纵轴 | 名称 “Number of Orders”；单位为订单计数（原始数据未给更细单位）；合同范围 0–60，刻度间隔 10 |
| 系列与图例 | 单一系列 Orders = 22、28、25、36、44、41、53（按 Jan→Jul）；单系列不额外生成图例含义 |
| 数据形状 | 7 类别 × 1 系列 = 7 个数值点 |

## 数据保真要求（必须遵守）
1. **不归一化**：不做 min-max 缩放、百分比化、指数化或任何形式的重标定；数值按原样进入图表。
2. **不插值、不外推**：7 个月份点直接连线，不补充任何中间月份（如半月、周）；4 个季度不插入额外类别。
3. **不改写类别名称或顺序**：Q1–Q4 与 Jan–Jul 的文本与排列顺序保持原样，不翻译、不缩写、不重排、不按数值排序。
4. **不增加数据点**：不添加合计柱、平均线、目标差额、达成率、趋势线或任何派生系列；系列仅有 Target、Actual、Orders 三个原始名称。
5. **不合并两面板数据**：季度与月份的时间粒度、量纲、单位均不同，禁止拼接成同一序列或同一坐标轴。
6. **单位只按轴标签陈述**：仅使用 “million USD” 与 “订单数” 这两项已声明单位，不臆造货币换算或业务口径。
7. **缺口保持未知**：原始数据未提供的数据（如精度说明、缺失值、目标定义）不补造。

## 一处需要说明的交付限制
装配层的坐标系统只能记录轴的类型与轴名称（如 “Quarter” / “Revenue (million USD)”），**纵轴的具体上下限（0–70、0–60）与刻度步长（10）无法逐项写入图表结构**，实际刻度将由传入数据自动决定。因此合同中的 0–70 / 0–60 与 step=10 属于数据约定，绘制时可能不会逐字显示为源数据声明的刻度；这不影响数值本身，但若你要求刻度必须严格为 0–70 / 0–60、每 10 一格，需要在绘制后按实际渲染结果核对，并可能需要接受渲染器的自动刻度。
