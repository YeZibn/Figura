# 图表构建评分表（评测人员专用）

每项记 `通过 / 未通过 / 不适用` 并保存证据。所有关键项通过才算本任务通过。

| 检查项 | 类型 | 通过标准 |
|---|---|---|
| 面板数量与顺序 | 关键 | 恰有两个面板；季度销售在左，月度订单在右。 |
| 图表类型 | 关键 | 左侧为分组柱状图，右侧为折线图。 |
| 季度数据 | 关键 | Target 与 Actual 的四个值、系列归属及 Q1—Q4 顺序全对。 |
| 月度数据 | 关键 | Orders 的七个值及 Jan—Jul 顺序全对。 |
| 轴与刻度 | 关键 | 轴标签、单位、范围和刻度步长与输入一致。 |
| 最终标题 | 关键 | 总标题为“季度销售与月度订单”。 |
| 历史核对 | 关键 | 按提示执行历史搜索与引用读取；Q3 Target=48、Q3 Actual=45、Jul Orders=53。 |
| 产物可用 | 关键 | 返回有效 ChartSpec，PNG 可打开且包含两个面板。 |
| 数据保真 | 关键 | 未归一化、插值、重排、改名、合并或新增数据。 |
| 视觉可读性 | 质量 | 标签、图例和刻度可辨认，无明显裁切或重叠。 |
