# 固定对话脚本：图表构建

首轮附加 `input/dataset.json`，后两轮不要重复附加。按顺序发送，不增删提示。

## 第 1 轮：建立数据合同

请读取附件中的结构化数据，说明其中有几个面板、每个面板的图表类型、类别、系列和单位。先建立数据合同，不绘图；不要合并两个面板的数据，也不要从系列名推测额外数据。

## 第 2 轮：补充布局和保真要求

最终图表采用一行两列布局，左侧为季度销售分组柱状图，右侧为月度订单折线图。每个面板保留自己的标题、横轴类别顺序、纵轴名称、单位和刻度范围；季度销售图显示 Target 与 Actual 图例。不要归一化数值、插值、改写类别名称或增加数据点。请复述当前有效的图表合同和数据保真要求。

## 第 3 轮：历史核对并交付

最终总标题使用“季度销售与月度订单”。请先通过 `search_history` 找回季度销售 Q3 的 Target、Actual 数值，以及 7 月 Orders 数值，再用 `read_history` 按返回引用读取原始数据；确认分别为哪个面板和系列后，调用 `assemble_chart_figure` 与 `render_chart_figure` 装配并渲染最终图表。交付 ChartSpec 摘要和 PNG，并说明你检查过面板顺序、类别顺序、单位及原始数值没有变化。若历史记录与当前要求冲突，以本轮最后确认的图表合同为准。
