# 图表分析评分表（评测人员专用）

每项记 `通过 / 未通过 / 不适用`，并摘录 Agent 回答或工具引用作为依据。以下关键项全部通过，任务才通过。

数值来自图像几何读取：若回答明确标注为估算，绝对误差不超过 1 个数据单位可通过；未标注估算的数值必须与标准答案一致。系列、类别和单位没有误差容差。

| 检查项 | 类型 | 通过标准 |
|---|---|---|
| 面板识别 | 关键 | 正确识别为两个独立面板，并分别对应季度销售与月度订单。 |
| 图表类型 | 关键 | 季度销售为分组柱状图，月度订单为折线图。 |
| 类别与系列结构 | 关键 | 类别顺序及系列归属均与标准答案一致。 |
| 全部数据值 | 关键 | 两个面板全部数值符合上述容差；估算声明另行记录。 |
| 轴标签与单位 | 关键 | 两个纵轴标题和单位没有互换或混淆。 |
| 季度差值 | 关键 | `Target - Actual` 为 4、4、3、3；最大/最小并列季度正确。 |
| 月度变化 | 关键 | 净变化 +31，最低 Jan=22，最高 Jul=53。 |
| 历史检索 | 关键 | 按第三轮要求使用 `search_history` 与 `read_history`，引用内容对应正确来源。 |
| 历史事实回答 | 关键 | Q3 Target=48、Q3 Actual=45、May=44、Jul=53。 |
| 结论边界 | 质量 | 只描述数据，不将相关变化写成无依据的因果。 |
