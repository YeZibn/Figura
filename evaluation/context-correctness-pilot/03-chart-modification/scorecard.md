# 图表修改评分表（评测人员专用）

每项记 `通过 / 未通过 / 不适用` 并保存证据。所有关键项通过才算本任务通过。

原始数值由图像读取：单个值与标准答案的绝对误差不超过 1 万元可通过；系列归属、季度顺序及单位必须完全正确。评分时同时记录 Agent 最终写入 ChartSpec 的值。

| 检查项 | 类型 | 通过标准 |
|---|---|---|
| 图表方向与模式 | 关键 | 最终为纵向分组柱状图，不是横向或堆叠图。 |
| 类别顺序 | 关键 | 第一季度、第二季度、第三季度、第四季度。 |
| 系列顺序 | 关键 | 华东、华南、华北。 |
| 原始数据保留 | 关键 | 三个系列的全部 12 个值均在上述容差内；没有新增预测值。 |
| 最终标题与单位 | 关键 | 标题为“2025 年各区域季度销售额（万元）”，纵轴单位为万元。 |
| 最终颜色 | 关键 | 三个系列的颜色代码均正确映射。 |
| 数值标签与来源 | 关键 | 柱上显示数值标签，来源为“Figura 合成样例数据”。 |
| 撤销要求处理 | 关键 | 没有沿用横向布局或按第四季度值重排区域。 |
| 产物可用 | 关键 | 返回有效 ChartSpec，PNG 可打开，系列和标签可辨认。 |
| 视觉可读性 | 质量 | 标题、图例、刻度和数值标签无明显遮挡或裁切。 |
