Codex 必须看实际任务输出。如果百分比在正式输出中被遮到歧义或错误，应按渲染关键项失败；不能因存在相同问题的参考诊断图而通过。既不允许擅改要求的内半径，也不要求 Agent 使用当前工具以外的能力。
