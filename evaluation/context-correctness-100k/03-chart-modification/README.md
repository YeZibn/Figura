# 03 图表修改（100k）

## 输入

只在第 1 轮附加 `input/quarterly-regional-sales.png`。图像包含三个有清晰数值标注的面板；输入哈希在运行 manifest 中记录。可由 `generate_fixtures.py` 确定性重建。

## 目标

从图像建立完整三面板 Figure，按 34 轮指令修改目标子图，处理临时方案撤销，并通过多轮定量核算保持非目标面板和原始值不变。第 33 轮从资源目录读取初始 ChartFigure，第 34 轮完成最终重组和渲染。

## 可评分修改范围

允许修改 ChartFigure 标题/列数、ChartSpec 的标题、来源、备注、轴标签和有明确用户依据的数据值。不要要求自定义颜色、笛卡尔轴范围/刻度步长或任意柱上数值标签。
