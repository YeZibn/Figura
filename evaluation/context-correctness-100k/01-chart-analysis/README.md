# 01 图表分析（100k）

## 输入

只向 Agent 附加 `input/bar_line_dashboard.png`。图内有四个面板，数值均有明确标注；答案键记录全部面板值及计算目标。运行前由 `generate_fixtures.py` 可确定性重建图片。

## 目标

在 20 轮分析中保持面板、系列、类别、单位、原始值和计算关系；压缩后按资源目录中的类型化引用读取早期 OCR/测量结果，继续核对和计算。报告轮逐步累积完整数据台账和派生统计，验证长会话状态保持。

## 关键约束

- 图中明确标注的数值按精确值评分；若模型确实只能按坐标轴估读，必须标记估算，并使用答案键容差。
- 不要求因果解释，不得把相关趋势写成因果关系。
- 第 19 轮包含资源核对，第 20 轮完整交付，是压缩后正确性观察窗口；若此前没有成功压缩，结果不计入压缩后正确率。
