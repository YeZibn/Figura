# 02 图表构建（100k）

## 输入

第 1 轮把 `input/dataset.json` 原文嵌入用户消息。JSON 是合成运营数据，含四个有序图表数据合同和 88 个数据位置（含两个明确缺失值）。答案键和评分表不得发送给 Agent。

## 目标

在 30 轮中递进装配一个四面板 ChartFigure，并完成年度/地区汇总、局部布局候选撤销和数据完整性审计；持续保持面板、类别、系列、空值语义及数据源不变。第 29 轮从历史资源读取 Figure，第 30 轮完成渲染交付。

## 图表合同边界

四个子图分别为 grouped bar、line、heatmap 和 scatter。只要求 Schema 支持的 Figure 标题/列数、ChartSpec 标题/来源/备注、轴种类/标签、数据类型和顺序；不要求自定义笛卡尔轴范围、刻度步长、颜色或任意数据标签。
