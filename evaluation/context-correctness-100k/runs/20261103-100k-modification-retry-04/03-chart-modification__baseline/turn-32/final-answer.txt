## 5. 修订来源说明（July 105 → 109）

| 项 | 内容 |
|---|---|
| 源图 | `quarterly-regional-sales.png` |
| 源图读数 | July = **105**（图上折线点旁的打印标注，OCR 识别一致） |
| 修订值 | July = **109** |
| 依据 | 用户核实订单台账后确认；属用户权威断言，本会话未独立查看台账 |
| 修订命令 | “只将 Monthly Orders 的 July 从 105 更新为 109；在该面板 note 中记录 July corrected from the source ledger.；不要把源图读数 105 从历史事实中抹去；不要修改其他月份” |
| 影响面 | 仅该面板 1 个数据点；全序列合计 1 293 → 1 297（+4），月均 107.75 → 108.083（+1/3）；Q3 月均 114.333 → 115.667（+4/3） |
| 溯源留存 | 数据字段为 109；note 同时含修订来源句与“（源图 July 为 105）”括注，105 未被删除 |
| 性质 | 源图标注与台账实际不符；修订在同一下标位置抬高数值，未移动月份、未改动相邻月份 |
