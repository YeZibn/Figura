## 计算过程（可复核）

| 统计量 | 数值 |
|---|---|
| n | 12 |
| Σx | 1,987 |
| Σy | 49.5 |
| Σxy | 8,401.4 |
| Σx² | 339,939 |
| Σy² | 208.09 |
| x̄ | 165.5833 |
| ȳ | 4.1250 |
| Sxy = Σxy − n·x̄·ȳ | 8,401.4 − 8,196.375 = **205.0250** |
| Sxx = Σx² − n·x̄² | 339,939 − 329,014.0833 = **10,924.9167** |
| Syy = Σy² − n·ȳ² | 208.09 − 204.1875 = **3.9025** |

r = Sxy ÷ √(Sxx · Syy) = 205.0250 ÷ √(10,924.9167 × 3.9025) = 205.0250 ÷ 206.4812 ≈ **0.992949**

补充指标：决定系数 r² ≈ **0.986**，即在样本内，两个序列的线性共同变化可解释约 98.6% 的方差份额（该数值同样是描述性统计量）。

## 如何理解这个数字

- **只能说明“共同变化”**：r 接近 +1 表示两列数值在 12 个月的排序与间距上高度同步——订单数较高的月份，转化率也较高；反之亦然，且这种同步接近一条直线。
- **不表明二者互相引起**：订单高并不意味着转化率高是原因，转化率高也不意味着订单因此增加。二者可能同时受第三因素驱动（如促销期、季节性、流量规模、页面改版、渠道结构变化等），而本图没有任何这类信息，因此不能从 r 推断因果、方向性或影响大小。
- **注意这是“同月同趋势”相关，不是“变化量”相关**：两列都带明显上行时间趋势，趋势本身会推高 Pearson r；若把趋势剔除（例如对月份做去趋势或改用差分后的变化量），相关系数通常会明显下降。因此 r=0.993 更适合读作“同向同速上行”，而不是“每增加 1 单转化率就上升多少”。
- **样本很小**：n = 12，单月异常值即可显著改变 r；且转化率是以 % 记录、订单以“单”记录，量纲通过标准化消除，r 本身无量纲，不能解读为“订单每增加 1 个单位，转化率增加 x%”。
- **数值层面无不确定项**：24 个输入值全部是图上打印标签（订单 12/12、转化率 12/12 已逐项确认），因此 r 的差异只可能来自口径选择（如是否去趋势、是否用秩相关），而非读数误差。若改用 Spearman 秩相关，排序上仅 Mar、Jul、Oct 三个小幅回落的错位会影响名次，但整体仍会是接近 1 的强正相关。
