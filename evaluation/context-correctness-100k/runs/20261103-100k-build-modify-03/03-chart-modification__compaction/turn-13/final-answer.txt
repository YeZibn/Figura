**两套序列（Jan–Dec Orders）**

| 月份 | 源图序列 | 修订序列 | 差异 |
|---|---|---|---|
| Jan | 82 | 82 | 0 |
| Feb | 90 | 90 | 0 |
| Mar | 87 | 87 | 0 |
| Apr | 95 | 95 | 0 |
| May | 101 | 101 | 0 |
| Jun | 108 | 108 | 0 |
| **Jul** | **105** | **109** | **+4** |
| Aug | 115 | 115 | 0 |
| Sep | 123 | 123 | 0 |
| Oct | 119 | 119 | 0 |
| Nov | 130 | 130 | 0 |
| Dec | 138 | 138 | 0 |
| **合计** | **1293** | **1297** | **+4** |

**1. 修订差值**
- July：109 − 105 = **+4 单**（相对原值 +3.8%，4/105）
- 全年合计随之由 1293 → 1297，增量为 **+4**，只来自这一点

**2. 全年月均 Orders**
- 源图序列：1293 ÷ 12 = **107.75**
- 修订序列：1297 ÷ 12 = **108.08**（108.0833…）
- 变化：**+0.33 单/月**（+4/12 ≈ +0.3333；相对提高约 +0.31%）

**3. Q3（Jul、Aug、Sep）月均 Orders**
- 源图序列：105 + 115 + 123 = 343 → 343 ÷ 3 = **114.33**（114.3333…）
- 修订序列：109 + 115 + 123 = 347 → 347 ÷ 3 = **115.67**（115.6667…）
- 变化：**+1.33 单/月**（+4/3 ≈ +1.3333；Q3 合计由 343 → 347）

**4. 除 July 外其他月份均保持原值**
- Jan 82、Feb 90、Mar 87、Apr 95、May 101、Jun 108、Aug 115、Sep 123、Oct 119、Nov 130、Dec 138 在两层序列中逐位相同，未随修订改动。
- 因此全年极值与端点变化也不受影响：最大值仍为 Dec 138，最小值仍为 Jan 82，Jan→Dec 净变化仍为 +56。

**补充说明**
- 修订只影响“单点 → 月度汇总 → 季度汇总”这条汇总链的数值；Q3 之外季度的月均与合计完全不变（Q1 合计 259、均值 86.33；Q2 合计 304、均值 101.33；Q4 合计 387、均值 129.00），因为 July 不在其中。
- 均值差异很小（全年 +0.33、Q3 +1.33），源于单个点被修正且幅度仅 4；但方向与幅度并非重复读数的随机波动，而是你基于订单台账一次性确认的修订。
- 105 仍是源图的原始读数事实（图像标注与 OCR 均如此），109 是修订值；最终 Figure 采用 109，并在 Monthly Orders 面板 note 中写明 `July corrected from the source ledger.`。
